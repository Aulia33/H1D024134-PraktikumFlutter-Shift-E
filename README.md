    * Mengimplementasikan `_showDialog()` untuk menampilkan pop-up konfirmasi (`AlertDialog`).
    * Menambahkan logika autentikasi: jika username dan password adalah `admin`, sistem menyimpan sesi pengguna dan berpindah ke `HomePage`; jika tidak sesuai, sistem menampilkan dialog kesalahan.

    * Mengonfigurasi `MaterialApp` dengan tema Material klasik biru (`primarySwatch: Colors.blue`, `useMaterial3: false`) agar serasi dengan desain modul.

  * **Halaman Utama (`home_page.dart`)**:
    * Menggunakan fungsi asinkronus `_loadUsername()` untuk membaca data username yang telah tersimpan di `SharedPreferences` saat halaman dimuat.

## 📝 Tugas Pertemuan 4: Operasi CRUD dengan API CodeIgniter 4 & Flutter Tokokita
**Tanggal**: Rabu, 11 November 2026

### Deskripsi Teknis & Non-Teknis
* **Non-Teknis**: Memahami dan mengimplementasikan arsitektur RESTful API sebagai penghubung komunikasi data antara backend server (CodeIgniter 4 & database MySQL) dengan aplikasi client mobile (Flutter). Mempelajari pembuatan model data (serialization/deserialization JSON), validasi form input yang komprehensif, serta antarmuka operasi CRUD (Create, Read, Update, Delete) produk pada aplikasi mobile.
* **Teknis**:
  * **1. Backend & Database (CodeIgniter 4 & MySQL)**:
    * Membuat database `toko_api` pada MySQL dengan tabel: `member`, `member_token`, dan `produk`.
    * Membuat controller induk `RestfulController` yang mengekstend `ResourceController` CodeIgniter 4 dengan standarisasi response JSON (`code`, `status`, `data`).
    * Membuat model `MRegistrasi`, `MMember`, `MLogin`, dan `MProduk`.
    * Membuat controller:
      * `RegistrasiController`: Melakukan enkripsi password dengan `password_hash` dan menyimpan data member baru.
      * `LoginController`: Memvalidasi email dan verifikasi password (`password_verify`), membuat auth token acak, dan menyimpannya ke tabel `member_token`.
      * `ProdukController`: Menangani operasi CRUD produk (`create`, `list`, `detail`, `ubah`, `hapus`).
    * Mendaftarkan rute API di `Routes.php` untuk endpoint `/registrasi`, `/login`, dan grup `/produk` (GET, POST, PUT, DELETE).
  * **2. Model Data Flutter (`lib/model/`)**:
    * `Login` (`model/login.dart`): Memetakan respons autentikasi (`code`, `status`, `token`, `userID`, `userEmail`) dengan factory constructor `fromJson`.
    * `Registrasi` (`model/registrasi.dart`): Memetakan respons pendaftaran member baru.
    * `Produk` (`model/produk.dart`): Memetakan data produk (`id`, `kodeProduk`, `namaProduk`, `hargaProduk`).
  * **3. Antarmuka Pengguna Flutter (`lib/ui/`)**:
    * **Halaman Registrasi (`ui/registrasi_page.dart`)**:
      * Form registrasi dengan `GlobalKey<FormState>()`.
      * Validasi nama (minimal 3 karakter).
      * Validasi format email menggunakan ekspresi reguler (RegExp).
      * Validasi panjang password (minimal 6 karakter).
      * Validasi konfirmasi password agar harus sama dengan password yang diinputkan.
    * **Halaman Login (`ui/login_page.dart`)**:
      * Form login dengan validasi field email dan password.
      * Tautan teks `InkWell` untuk membuka halaman registrasi (`RegistrasiPage`).
      * Tombol Login yang mengarahkan ke halaman `ProdukPage`.
    * **Halaman List Produk (`ui/produk_page.dart`)**:
      * Menampilkan daftar item produk menggunakan widget `ListView` dan widget modular `ItemProduk` (`Card` & `ListTile`).
      * Tombol ikon tambah (`+`) di `AppBar` untuk membuka halaman `ProdukForm`.
      * Navigasi drawer dengan menu `Logout`.
      * Navigasi klik item produk menuju halaman `ProdukDetail`.
    * **Halaman Form Produk (`ui/produk_form.dart`)**:
      * Memiliki 2 fungsi (tambah & ubah data).
      * Otomatis mendeteksi status form pada `initState()` melalui fungsi `isUpdate()`: jika menerima parameter objek `Produk`, form beralih ke mode *"UBAH PRODUK"* dengan tombol *"UBAH"*; jika null, form berada pada mode *"TAMBAH PRODUK"* dengan tombol *"SIMPAN"*.
    * **Halaman Detail Produk (`ui/produk_detail.dart`)**:
      * Menampilkan rincian kode, nama, dan harga produk.
      * Tombol aksi **EDIT** (warna hijau) yang membuka `ProdukForm` membawa data produk yang sedang dilihat.
      * Tombol aksi **DELETE** (warna merah) yang memicu pop-up konfirmasi `AlertDialog` (*"Yakin ingin menghapus data ini?"*).
